# Data Product Sandbox

A sandbox repository for our data product management team to explore **Cursor** and **Git** together.

## Purpose

This repo is a safe space to:

- **Try Cursor** — Experiment with AI-assisted editing, chat, and code generation
- **Practice Git** — Create branches, make commits, push changes, and collaborate
- **Learn workflows** — See how Cursor and Git fit into your daily work

## Getting Started

1. **Clone** this repo (if you haven’t already)
2. **Open** the folder in Cursor
3. **Experiment** — Add files, ask Cursor for help, and commit your changes

## Ideas to Try

- Add a spec or requirements doc and ask Cursor to refine it
- Create a simple data dictionary or schema and iterate on it
- Draft SQL or pseudocode and have Cursor help structure it
- Use branches to try different approaches without affecting `main`
