# Learnings

Captured insights from our work sessions — what we tried, what worked, what didn't, and what we'd do differently.

## Purpose

- **knowledge/** = curated reference materials (how-to guides, indexes)
- **learnings/** = emergent insights from actual sessions (discoveries, gotchas, patterns)

## How to Use

1. **During or after a session**, paste the [extract prompt](prompt-template-extract.md) into chat
2. The AI will distill learnings from the conversation
3. Add the output to this directory (e.g. `YYYY-MM-DD-session-topic.md` or append to a running log)

## Naming

- `YYYY-MM-DD-short-topic.md` — one file per session or topic
- Or a single `log.md` if you prefer a chronological stream
