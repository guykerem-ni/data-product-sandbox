# Extract Learnings — Prompt Template

Copy everything below the line into your Cursor chat when you want to capture learnings from this session.

---

**Extract learnings from this session.**

Review our conversation and the work we did. Produce a structured summary I can add to `learnings/` in this repo.

**Include:**

1. **Context** — What we were trying to do (1–2 sentences)
2. **Learnings** — Bullet points of what we discovered, what worked, what didn't, gotchas, or patterns worth remembering
3. **Artifacts** — Any files we created or changed that matter for future reference
4. **Follow-ups** — Open questions, next steps, or things to try later (if any)

**Format** the output as a markdown block I can save directly as `learnings/YYYY-MM-DD-short-topic.md`. Use today's date and a brief topic slug.

Keep it concise. Focus on what would help someone (or future-you) in a similar situation.
